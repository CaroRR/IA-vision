# Sylva AI — Fire and Smoke Detection

Proyecto de experimentación y evaluación de modelos de
detección de incendios forestales mediante visión por computadora.

## Experimentos

- Comparación de modelos YOLO para detectar fuego y humo.
- Evaluación con el dataset wildfire.
- Fine-tuning de modelos preentrenados.
- Análisis de precisión, recall, mAP y velocidad de inferencia.

## Clases

- 0: smoke
- 1: fire
